# Jogo da Velha PIT

## Sobre o projeto

O Jogo da Velha PIT é um projeto acadêmico desenvolvido em Python para a disciplina de Lógica, Algoritmos e Programação do curso de Tecnologia em Banco de Dados.

O objetivo é desenvolver um jogo da velha executado pelo terminal, aplicando os conhecimentos de lógica de programação, funções, estruturas condicionais e validação de dados.
