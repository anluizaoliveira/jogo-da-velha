# Jogo da Velha PIT

## Sobre o projeto

O Jogo da Velha PIT é um projeto acadêmico desenvolvido em Python para a disciplina de Lógica, Algoritmos e Programação do curso de Tecnologia em Banco de Dados.

O objetivo é desenvolver um jogo da velha executado pelo terminal, aplicando os conhecimentos de lógica de programação, funções, estruturas condicionais e validação de dados.

## 4. Funcionalidades

O projeto está sendo desenvolvido com as seguintes funcionalidades:

- Menu principal para navegação.
- Iniciar uma partida de jogo da velha.
- Exibir as regras do jogo.
- Registrar e consultar o placar.
- Consultar o histórico de partidas.
- Apresentar estatísticas.
- Exibir um ranking de jogadores.
- Opção para sair do jogo.

As funcionalidades são implementadas e testadas durante o desenvolvimento do projeto.

## 5. Regras do jogo

O jogo da velha é disputado em um tabuleiro de 3x3, por dois jogadores.

- Um jogador utiliza o símbolo **X** e o outro utiliza o símbolo **O**.
- Os jogadores escolhem alternadamente uma posição no tabuleiro.
- Não é permitido escolher uma posição que já esteja ocupada.
- Vence quem conseguir formar uma sequência de três símbolos iguais na horizontal, vertical ou diagonal.
- Caso todas as posições sejam preenchidas sem um vencedor, a partida termina empatada.

## 6. Como executar o projeto

Para executar o jogo, é necessário ter o Python instalado no computador.

**Passo a passo:**

1. Baixe ou clone o repositório do projeto.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal.
4. Execute o seguinte comando:

```bash
python jogodavelhapit.py
```

5. Aguarde a inicialização do jogo e utilize as opções apresentadas no menu.
